# Права доступа

## Гость
- Может открыть главную страницу
- Может зарегистрироваться
- Может войти в аккаунт
- Не может создавать заметки

## User
- Может создавать свои заметки
- Может просматривать свои заметки
- Может редактировать только свои заметки
- Может удалять только свои заметки
- Может оставлять комментарии
- Может создавать свои события в календаре
- Может редактировать свой профиль

## Admin
- Может всё, что умеет User
- Может просматривать любые заметки
- Может редактировать любые заметки
- Может удалять любые заметки
- Может удалять любые комментарии
- Может просматривать список пользователей
