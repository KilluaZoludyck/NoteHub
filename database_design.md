# Схема базы данных NoteHub

## users
Хранит пользователей системы.

- id — уникальный идентификатор
- username — имя пользователя
- email — электронная почта
- password_hash — хеш пароля
- role — роль: user или admin
- avatar_url — ссылка на аватар
- bio — описание профиля
- created_at — дата регистрации

## notes
Хранит заметки.

- id — уникальный идентификатор
- title — заголовок
- content — текст заметки
- author_id — ID автора
- is_public — публичная или личная заметка
- created_at — дата создания
- status - статус заметки
- tags - теги

## comments
Хранит комментарии к заметкам.

- id — уникальный идентификатор
- note_id — ID заметки
- author_id — ID автора комментария
- content — текст комментария
- created_at — дата создания
- updated_at — дата изменения

## events
Хранит события календаря.

- id — уникальный идентификатор
- user_id — ID владельца события
- note_id — связанная заметка, необязательно
- title — название события
- description — описание
- start_at — начало события
- end_at — окончание события
- status — статус события
- created_at — дата создания

## tags
Хранит теги.

- id — уникальный идентификатор
- name — название тега

## note_tags
Связывает заметки и теги.

- note_id — ID заметки
- tag_id — ID тега
