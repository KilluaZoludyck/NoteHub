# Технологический стек NoteHub

## Backend
- Python 3.11+
- Flask
- Flask-SQLAlchemy
- Flask-Migrate
- Flask-Login
- Flask-WTF
- Werkzeug

## База данных
- SQLite

## Frontend
- HTML5
- CSS3
- JavaScript
- Jinja2
- Bootstrap 5

## Инструменты
- Git
- GitHub
- VS Code или PyCharm
- DB Browser for SQLite
- GitHub Projects

## Что не входит в MVP
- PostgreSQL
- Docker
- REST API
- React / Vue
- Telegram-бот
- Комментарии
- Полноценный календарь
- Теги
- Загрузка файлов
- Email-подтверждение
- Восстановление пароля
