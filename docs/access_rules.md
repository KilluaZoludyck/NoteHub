# Права доступа NoteHub

## Гость

Может:
- Открыть главную страницу
- Зарегистрироваться
- Войти в аккаунт

Не может:
- Создавать заметки
- Просматривать заметки
- Открывать профиль
- Открывать админ-панель

## User

Может:
- Создавать свои заметки
- Просматривать свои заметки
- Редактировать свои заметки
- Удалять свои заметки
- Просматривать публичные заметки других пользователей
- Просматривать свой профиль
- Редактировать имя пользователя и описание
- Искать свои заметки по заголовку

Не может:
- Редактировать чужие заметки
- Удалять чужие заметки
- Просматривать чужие личные заметки
- Открывать админ-панель
- Менять собственную роль на admin

## Admin

Может:
- Всё, что может User
- Просматривать любые заметки
- Редактировать любые заметки
- Удалять любые заметки
- Просматривать список пользователей
- Просматривать профили пользователей
- Просматривать статистику

Не может:
- Удалить единственного администратора
- Удалить себя, если он единственный admin
