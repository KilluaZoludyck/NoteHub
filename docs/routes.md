# Маршруты NoteHub

## Главные страницы

| Метод | Маршрут | Доступ | Назначение |
|---|---|---|---|
| GET | / | Все | Главная страница |
| GET | /about | Все | О проекте |

## Авторизация

| Метод | Маршрут | Доступ | Назначение |
|---|---|---|---|
| GET | /register | Гость | Форма регистрации |
| POST | /register | Гость | Создание аккаунта |
| GET | /login | Гость | Форма входа |
| POST | /login | Гость | Авторизация |
| GET | /logout | Авторизованный | Выход |

## Профиль

| Метод | Маршрут | Доступ | Назначение |
|---|---|---|---|
| GET | /profile | Авторизованный | Свой профиль |
| GET | /profile/<int:user_id> | Авторизованный | Профиль пользователя |
| GET | /profile/edit | Авторизованный | Редактирование профиля |
| POST | /profile/edit | Авторизованный | Сохранение профиля |

## Заметки

| Метод | Маршрут | Доступ | Назначение |
|---|---|---|---|
| GET | /notes | Авторизованный | Мои заметки |
| GET | /notes/public | Авторизованный | Публичные заметки |
| GET | /notes/new | Авторизованный | Создание заметки |
| POST | /notes/new | Авторизованный | Сохранение заметки |
| GET | /notes/<int:note_id> | По правам | Просмотр заметки |
| GET | /notes/<int:note_id>/edit | Автор или admin | Редактирование |
| POST | /notes/<int:note_id>/edit | Автор или admin | Сохранение изменений |
| POST | /notes/<int:note_id>/delete | Автор или admin | Удаление |

## Администрирование

| Метод | Маршрут | Доступ | Назначение |
|---|---|---|---|
| GET | /admin | Admin | Панель администратора |
| GET | /admin/users | Admin | Список пользователей |
| GET | /admin/notes | Admin | Все заметки |
